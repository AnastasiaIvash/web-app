# Веб-приложение для тестирования балансировки нагрузки и отказоустойчивости 

## Архитектура и стек технологий

* **Язык / Фреймворк:** Python 3.11+ / FastAPI (поддержка асинхронных запросов `async/await`).
* **Хранилище сессий и данных:** Redis (внешнее centralized in-memory хранилище).
* **Контейнеризация:** Docker.

Приложение спроектировано по принципу Stateless, что позволяет запускать произвольное количество идентичных экземпляров (нод) за балансировщиком нагрузки.

---

   * Каждый экземпляр приложения считывает имя хоста (`socket.gethostname()`) или переменную окружения `NODE_ID`.
   * Все эндпоинты API (`/`, `/api/info`, `/api/session/...`) явно возвращают идентификатор ноды `node_id`, вызванной балансировщиком.
   * Все операции чтения и записи вынесены во внешний Redis (`REDIS_HOST`).
   * Выход из строя одной или нескольких нод backend не приводит к недоступности или потере данных — оставшиеся ноды продолжают работу с единой базой.
   * Приложение работает по протоколу HTTP и принимает незашифрованный трафик.
   * Обработка сертификатов и TLS-терминация делегированы внешнему реверс-прокси (Nginx/Apache), который будет настроен в Лабораторной работе №3.
   * Использование оперативной памяти процесса или локальных файлов ноды для хранения пользовательских сессий полностью исключено.
   * Сессии и состояние сохраняются исключительно в распределенном кэше Redis.

## Эндпоинты API

| Метод | Эндпоинт | Описание |
| :--- | :--- | :--- |
| `GET` | `/` | Возвращает статус приложения и `node_id` обработавшего узела. |
| `GET` | `/docs/` | Возвращает интерфейс приложения. |
| `GET` | `/api/info` | Возвращает ID ноды, IP клиента и заголовки запроса (например, `X-Forwarded-For`). |
| `POST` | `/api/session/set?key=K&value=V` | Записывает сессионные данные во внешний Redis. |
| `GET` | `/api/session/get/{key}` | Считывает данные сессии из внешнего Redis. |

## Инструкция по сборке 

### Сборка Docker-образа:
```bash
docker build -t backend-node:latest .
docker run -d --name redis-db -p 6379:6379 redis:alpine
docker run -d --name node0 -p 8001:8000 -e NODE_ID="node-00" -e REDIS_HOST="host docker.internal" backend-node:latest
```
